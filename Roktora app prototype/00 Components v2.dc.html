Reference sheet · 6 shared primitives

The parts every Roktora screen is built from

Each primitive uses role tokens only, so light and dark modes come for free. Status lives in color roles; urgency lives in a 2px stripe; trust lives in one badge shape.

01
BloodGroupPill

bg-{role} + text-{role}. Danger for Rh-negative shortages, warning for low, success for healthy, neutral when there's no stock context. Selected state adds a 2px accent border.

Picker variant — tap to select. Used in sign-up and filters.

EligibilityStepper

Five segments on the progress track. Done steps fill with progress-fill, current shows a numbered label, upcoming stays on track. Tap a segment to preview.

Elevation
No shadows. Floating planes (sheets, drawers) sit on surface-3 with a 0.5px border-strong. Two planes max.
Type
font-sans 400/500 for UI, font-voice for editorial moments (onboarding, thank-you notes), font-mono for IDs and codes.
Font substitution
Anthropic Sans isn't web-licensed here, so --font-sans maps to Instrument Sans with Hind Siliguri for Bangla. Swap the token to switch.
